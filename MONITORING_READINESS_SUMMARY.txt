PRODUCTION READINESS ISSUES:
-----------------------------

Issue 1: Trace Sampling Not Implemented
   Risk: High-volume agents will flood tracing backend
   Impact: Increased costs, backend overload, slow queries
   Fix Priority: CRITICAL (Weeks 1)
   
Issue 2: No Resource Metrics
   Risk: Cannot detect resource exhaustion (CPU, memory)
   Impact: Cascading failures, OOM errors, performance degradation
   Fix Priority: CRITICAL (Weeks 2-3)
   
Issue 3: No Alerting Rules
   Risk: Cannot respond to failures in time
   Impact: Extended outages, slow incident response
   Fix Priority: HIGH (Weeks 3-4)
   
Issue 4: No Health Probes
   Risk: Kubernetes cannot detect failed services
   Impact: Broken services stay in load balancer
   Fix Priority: HIGH (Weeks 2-3)
   
Issue 5: No Transport Instrumentation
   Risk: Cannot see network performance issues
   Impact: Hidden latency, connection errors undetected
   Fix Priority: MEDIUM (Weeks 4-6)
   
Issue 6: Duplicate Middleware
   Risk: Confusion about which to use (OpenTelemetry vs. local decorators)
   Impact: Metrics not exported, monitoring blind spots
   Fix Priority: MEDIUM (Weeks 2-3)
