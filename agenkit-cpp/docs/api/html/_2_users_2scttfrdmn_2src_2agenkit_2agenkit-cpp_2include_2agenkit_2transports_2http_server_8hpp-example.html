HTTP server for exposing agents via REST API.

HTTP server for exposing agents via REST APIWraps a local agent and exposes it via HTTP endpoints:

  • POST /process - Process a message
  • GET /health - Health check
auto agent = std::make_shared<EchoAgent>();
HttpServer server(agent, "127.0.0.1:8080");
// Run in background thread
std::thread server_thread([&]() {
server.serve();
});
// Later: stop server
server.stop();
server_thread.join();
