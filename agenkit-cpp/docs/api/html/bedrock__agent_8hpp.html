Detailed Description

Amazon Bedrock API adapter.

Provides integration with Amazon Bedrock's foundation models including Claude, Llama, Mistral, and Titan via the Converse API.

NOTE: This implementation requires the AWS SDK for C++ (aws-sdk-cpp) which must be installed separately. In particular, the bedrockruntime component is required.

Installation:

Install AWS SDK for C++

git clone –recurse-submodules https://github.com/aws/aws-sdk-cpp cd aws-sdk-cpp mkdir build && cd build cmake .. -DCMAKE_BUILD_TYPE=Release -DBUILD_ONLY="bedrock-runtime" make && sudo make install

See also
https://docs.aws.amazon.com/bedrock/latest/userguide/
