Detailed Description

File-based checkpoint storage

Organizes checkpoints as: checkpoints/ session-1/ checkpoint-uuid-1.json checkpoint-uuid-2.json session-2/ checkpoint-uuid-3.json

Thread-safe implementation using std::mutex.
