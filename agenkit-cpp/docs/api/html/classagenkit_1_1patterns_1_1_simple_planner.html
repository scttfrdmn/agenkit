Detailed Description

Simple planner implementation for basic use cases.

This planner uses an LLM agent to handle both planning and synthesis. For planning, it prompts the LLM to decompose the task. For synthesis, it prompts the LLM to combine results.

For production use, consider implementing a custom PlannerAgent with domain-specific planning and synthesis logic.
