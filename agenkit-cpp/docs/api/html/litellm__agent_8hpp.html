Detailed Description

LiteLLM proxy adapter for universal LLM access.

Provides integration with LiteLLM, a universal LLM gateway that offers an OpenAI-compatible API for 100+ LLM providers. Supports both completion and streaming modes.

See also
https://docs.litellm.ai/
