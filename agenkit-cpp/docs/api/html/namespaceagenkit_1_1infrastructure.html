◆ global_thread_pool()

ThreadPool & agenkit::infrastructure::global_thread_pool ( )

Get global thread pool instance.

Returns a reference to a singleton thread pool shared across the application. This eliminates the need to pass thread pools between components and provides a convenient default for async operations.

The pool is created with hardware_concurrency threads on first access and is automatically destroyed at program exit.

Returns
Reference to global thread pool
