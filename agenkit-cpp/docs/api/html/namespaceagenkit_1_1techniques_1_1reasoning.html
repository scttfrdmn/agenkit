◆ default_answer_extractor()

std::string agenkit::techniques::reasoning::default_answer_extractor ( const std::string & text)

Default answer extractor that looks for common answer patterns.

Patterns recognized:

  • "Therefore, X" / "Thus, X" / "So, X"
  • "The answer is X"
  • "= X" (for math)
  • "Conclusion: X" / "Result: X"
  • Last non-empty line (fallback)
Parameters
textInput text to extract answer from
Returns
Extracted answer
