Detailed Description

Tree-of-Thought Reasoning Technique.

Tree-of-Thought explores multiple reasoning paths simultaneously through tree search with branching, evaluation, pruning, and backtracking.

Reference: "Tree of Thoughts: Deliberate Problem Solving with Large Language Models" Yao et al., 2023 - https://arxiv.org/abs/2305.10601
