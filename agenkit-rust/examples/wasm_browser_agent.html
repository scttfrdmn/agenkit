ℹ️ Setup Instructions

  1. Install the WASM target: rustup target add wasm32-unknown-unknown
  2. Build the WASM package: wasm-pack build --target web --features wasm --no-default-features
  3. Serve this directory with a local server (e.g., python3 -m http.server)
  4. Open this page in your browser

Note: The WASM module will be loaded from ../pkg/agenkit.js
