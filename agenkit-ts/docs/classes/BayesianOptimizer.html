Class BayesianOptimizer

Bayesian Optimizer for intelligent hyperparameter search.

Uses a simplified surrogate model based on local statistics to guide the search process. Balances exploration (trying new areas) with exploitation (refining known good areas) using acquisition functions.

  • optimize(testCases, nIterations): Promise<OptimizationResult>

  • Run Bayesian optimization.

    Algorithm:

    1. Sample n_initial random configurations
    2. Evaluate and build local statistics
    3. Use acquisition function to select next config
    4. Evaluate new config
    5. Update statistics and repeat
