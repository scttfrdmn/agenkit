Class CostTracker

Track LLM costs per session, agent, and globally.

Features:

  • Per-session cost tracking
  • Per-agent cost tracking
  • Global cost tracking
  • Cost breakdown by model
  • Time-series cost data

Example: const tracker = new CostTracker(); await tracker.recordCost({ sessionId: 'user-123', agentName: 'assistant', model: 'claude-sonnet-4', inputTokens: 1000, outputTokens: 500, }); const total = await tracker.getSessionCost('user-123'); console.log(Session cost: $${total.toFixed(2)}); // Session cost: $0.01
