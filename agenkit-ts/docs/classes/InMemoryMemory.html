Class InMemoryMemory

Simple in-memory storage with LRU eviction.

Features:

  • Fast access (no I/O)
  • LRU eviction when max_size reached
  • Per-session storage
  • Optional metadata support

Limitations:

  • No persistence (data lost on restart)
  • No semantic search
  • Memory limited

Use cases:

  • Testing
  • Simple applications
  • Prototypes
  • When persistence not needed

Example: const memory = new InMemoryMemory({ maxSize: 1000 }); await memory.store('session-123', message); const messages = await memory.retrieve('session-123', { limit: 10 });
