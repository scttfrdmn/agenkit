Class LocalAgent

LocalAgent wraps a function to implement the Agent interface.

Features:

  • Zero network overhead
  • Full async/await support
  • Optional streaming support
  • Automatic message validation

Usage: const agent = new LocalAgent({ name: 'echo', process: async (msg) => ({ role: 'assistant', content: Echo: ${msg.content}, }), });

const response = await agent.process({ role: 'user', content: 'Hello!', });
