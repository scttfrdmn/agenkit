Class MetricsDecorator

Agent decorator that collects observability metrics.

Example: const metricsAgent = new MetricsDecorator(agent);

await metricsAgent.process(msg1); await metricsAgent.process(msg2);

const metrics = metricsAgent.getMetrics(); console.log('Average latency:', metrics.averageLatency, 'ms'); console.log('Error rate:', metrics.errorRate);
