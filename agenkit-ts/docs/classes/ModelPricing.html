Class ModelPricing

Pricing data for LLM models (as of January 2026).

All prices are per 1 million tokens (input and output separately).

Example: const pricing = new ModelPricing(); const cost = pricing.calculate('claude-sonnet-4', 10000, 'input'); console.log(Cost: $${cost.toFixed(4)}); // Cost: $0.0300
