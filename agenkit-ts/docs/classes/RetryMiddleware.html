Class RetryMiddleware

RetryMiddleware implements automatic retry with exponential backoff.

Features:

  • Configurable retry attempts
  • Exponential backoff
  • Customizable retry predicate
  • Preserves error stack traces

Usage: const agent = new RetryMiddleware(baseAgent, { maxAttempts: 3, initialDelay: 1000, backoffMultiplier: 2.0, });
