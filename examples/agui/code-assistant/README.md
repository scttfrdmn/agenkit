# Code Assistant

AI coding assistant with documentation search and code generation through AG-UI protocol.

## 🚀 Quick Start

```bash
docker-compose up --build
open http://localhost:3000
```

## Features

- ✅ **Code Generation**: Python, JavaScript, Go, Rust, TypeScript
- ✅ **Documentation Search**: Instant answers
- ✅ **Debugging Help**: Common issues and solutions
- ✅ **Best Practices**: Clean, documented code

## Usage

**Generate Code:**
- "Generate Python code for Fibonacci"
- "Create JavaScript API endpoint"

**Search Docs:**
- "Explain async in Python"
- "How to use promises in JavaScript"

**Debug:**
- "Help me debug this error"
- "Why isn't my code working"
